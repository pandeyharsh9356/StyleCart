# 🛍️ StyleCart – MERN Stack Fashion E-Commerce Platform

StyleCart is a full-stack fashion e-commerce platform built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The application provides a modern shopping experience with secure authentication, product management, online payments, and a responsive user interface.

## 🚀 Features

### Customer Features
- Browse fashion products
- Product categorization
- Secure user authentication
- Add to cart functionality
- Responsive design for mobile and desktop
- Online payment integration
- Fast and intuitive user experience

### Admin Features
- Product management
- Inventory control
- Category management
- Order monitoring
- Secure admin access

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/pandeyharsh9356/StyleCart.git
```

### Install Frontend Dependencies

```bash
cd admin
npm install
npm run dev
```

### Install Backend Dependencies

```bash
cd backend
npm install
npm start
```

### Environment Variables

Create a `.env` file and configure:

```env
MONGODB_URI=your_mongodb_uri
RAZORPAY_KEY=your_key
RAZORPAY_SECRET=your_secret
FIREBASE_CONFIG=your_firebase_config
JWT_SECRET=your_secret_key
```
